# Security Policy

## Reporting a Vulnerability

Do not disclose vulnerabilities, credentials, private data, or exploit details in a public issue, discussion, pull request, or fork.

Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the copyright holder through the private security contact published on the repository owner's GitHub profile.

Include the affected component and revision, reproduction prerequisites, impact, and a minimal proof of concept. Do not access data that is not yours, degrade service, establish persistence, or test production systems without explicit written authorization.

Please allow a reasonable period for validation and remediation before public disclosure. Permission to research the code is governed by [License.md](License.md).
